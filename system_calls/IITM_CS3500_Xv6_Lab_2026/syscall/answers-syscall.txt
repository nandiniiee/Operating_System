  7. We did num=*(int *)0 which tells the CPU to read an integer from virtual address 0. when the cpu tries to access VA 0, it goes to page table translation and find no valid mapping in there and thus a load page fault occurs. Basically, address 0 is not mapped in kernel's address space so we cannot translate the address to a valid physical page and thus a page fault is executed. Our scause was 0xd which is 13 which tells that it was load page fault.
