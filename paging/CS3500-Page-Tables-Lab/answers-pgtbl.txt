The pagetable program prints the page-table entries ofr the first 10 virtual pages and the last 10 virtual pages of the process.
For each entry of the page table, the page table entry contains the physical page number togehter with flags describing whether the page is valid or not and also tells us about read, write and execution permissions. 
The permission bits are- V Valid, R Read, W Write, X Execute, U User accessible, A accessed and D Dirty

First 10 virtual pages-
1. va 0x0 pte 0x21FC885B pa 0x87F22000 perm 0x5B
Meaning- contains the beginning of the user program's code. Mapped to physical address 0x87F22000. Permission is 0x5B which means 0101 1011 which means that the valid, read, execute, user and access bits are set. Hence, readable and executable but not writable. It is mapped because the process needs this page to execute its program
