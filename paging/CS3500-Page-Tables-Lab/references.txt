5. Prompt: Why does a superpage have to be aligned to its superpage size? Explain what could go wrong if the physical address or virtual address is not correctly aligned.
   THe response was: The LLM explained that larger page mappings rely on the lower address bits being zero according to the page size. Without the required alignment, the address cannot represent a valid mapping at that page-table level because some address bits that would normally be part of the page offset would conflict with the physical page number.
   How i sued it: I used this explanation when checking the alignment conditions in the superpage allocation and mapping code. It helped me understand why the assignment's alignment checks were necessary rather than treating them as arbitrary conditions.

9. Prompt: Explain how two free buddy blocks should be coalesced. How do I determine whether two blocks are actually buddies rather than merely adjacent in physical memory?
   The repsonse i got was: The LLM explained that physical adjacency alone is not sufficient. The buddy relationship comes from the recursive splitting hierarchy. The buddy address for a block of a particular order can be determined using the block size and the corresponding address relationship. Only blocks of the same order that are actual buddies should be merged.
   How i used it: I used this explanation to understand the distinction between adjacency and the buddy relationship. This was important when checking my coalescing logic because the assignment explicitly prohibits merging arbitrary adjacent blocks.
